# Emby.CrossLibraryCollections 🎬

> 自动将 Emby 媒体库中的**电影**与**电视剧**（如：动画 + 剧场版/OVA、漫威电影宇宙 MCU、星际迷航等）整合进同一合集 (Collections) 的 Emby 原生服务端插件。

---

## ✨ 核心特性

- 🌐 **跨库合集聚合**：打破 Emby 电影库与电视剧库的壁垒，将同 IP 系列的作品在“合集”中统一收纳展示。
- 🛡️ **单片多季防误判 (Anti-Season Sprawl)**：严格按顶级作品与全局媒体 ID（TMDb/IMDb/TVDb）去重统计，一部包含多个季的电视剧只算作 1 部独立作品，绝不发生“单剧多分季被误当作多部作品建合集”的现象。
- ✂️ **定界分隔词截断算法**：
  - 彻底杜绝“前两个字相同就误合并”的粗暴前缀匹配。
  - 基于可自由配置的定界分隔词（如“与”、“之”、“:”、“·”、“-”等）截断提取系列主名（如将《哈利·波特与魔法石》截为《哈利·波特》）。
  - 仅当同系列提取出的主名一致且独立作品数达标（默认 $\ge 2$）时才建立合集。
- 🏷️ **前置修饰词优先脱壳**：
  - 最高优先级预处理规则，匹配标题开头的“剧场版”、“【剧场版】”、“电影版”、“特别篇”、“OVA”等外壳修饰词。
  - 先完成前缀脱壳再进行系列比对，使剧场版与正片剧集无缝对齐。
- 🖼️ **合集封面海报自动提取**：合集生成或扫描后，若无封面，自动提取内部第一部影片的高清海报设置为合集封面，免去手动配图困扰。
- 🚫 **特定媒体库排除**：在设置界面动态勾选不参与扫描的库（如纯纪录片库、家庭录像库等），库内所有影片完全排除。
- 🔄 **清空并全量重新扫描创建**：设置页面提供手动“清空并重建”按钮，点击后一键清空旧合集并重新全量聚类；日常定时任务则保持平滑增量同步。
- 🧩 **原生嵌入 UI**：在 Emby 控制台插件页面中提供直观的配置表单，支持自由修改前置词、定界词、黑名单与别名映射规则。
- ⏰ **原生计划任务**：无须宿主机或 NAS 支持 Cron，直接利用 Emby 内置计划任务按设定的周期自动巡检。
- ☁️ **GitHub 自动化构建**：推送代码或发布 Tag 时由 GitHub Actions 自动编译输出 `.dll`。

## 🚀 安装与使用

### 1. 下载插件
前往本项目仓库的 [Releases 页面](../../releases)，下载最新版的 `Emby.CrossLibraryCollections.dll`（或 zip 压缩包并解压）。

### 2. 放置插件文件
将 `Emby.CrossLibraryCollections.dll` 放置于 Emby 服务端的 `plugins` 文件夹下：
- **Windows**: `C:\Users\<用户名>\AppData\Roaming\Emby-Server\programdata\plugins`
- **Docker**: 容器挂载的 `/config/plugins` 目录
- **群晖 / QNAP / Linux**: `~/.config/emby-server/plugins` 或 `/var/lib/emby-server/plugins`

### 3. 重启 Emby
重启 Emby Server，进入 **控制台 -> 插件**，即可看到 **Cross-Library Collections**。

## ⚙️ 配置说明

在 Emby 控制台点击本插件进入设置页面：

1. **运行与防护设置**：
   - **启用智能自动聚类**：根据清洗后的标题公共前缀自动推导同系列。
   - **最小成集条目数**：默认设为 `2`，防止库内只有单部作品时盲目建集。
   - **自动设置封面海报**：自动为新创建的合集继承子影片封面。
2. **排除媒体库**：
   - 勾选不需要参与合集聚合的媒体库。
3. **脱壳与定界词截断**：
   - **前置修饰词**：自定义脱壳词（如 `剧场版, 电影版, 动画, 电视剧, 特别篇, OVA, OAD, SP`）。
   - **定界分隔词**：截断词（如 `与, 之, ：, :, ·, -, －, ~, 篇`）。
4. **自定义系列映射**：
   - 针对译名完全不相关但属于同一宏大宇宙的作品（如《复仇者联盟》与《洛基》），可在下方点击 **+ 添加系列映射**：
     - **合集名称**：`漫威电影宇宙`
     - **匹配关键词**：`复仇者联盟,钢铁侠,美国队长,雷神,洛基,旺达幻视`
5. **重建与操作**：
   - **💾 保存配置**：保存当前修改项。
   - **🔄 清空并全量重新扫描创建**：一键清空由插件管理的合集并全量重新计算。
