# Emby.CrossLibraryCollections 🎬

> 自动将 Emby 媒体库中的**电影**与**电视剧**（如：动画 + 剧场版/OVA、漫威电影宇宙 MCU、星际迷航等）整合进同一合集 (Collections) 的 Emby 原生服务端插件。

---

## ✨ 核心特性

- 🌐 **跨库合集聚合**：打破 Emby 电影库与电视剧库的壁垒，将同 IP 系列的作品在“合集”中统一收纳展示。
- ⚡ **零标签运行 (Zero-Tags Required)**：针对 TMDb 中文标签缺失现象，插件通过标题清洗、最长公共前缀智能聚类及物理目录回溯，即使没有标签也能精准识别归并。
- 🛡️ **严格防误创机制 (Anti-Overfitting)**：
  - **分类黑名单**：严格过滤“动画”、“科幻”、“剧情”、“4K”等通用题材/参数标签，坚决防止泛化标签乱建合集。
  - **噪点剥离**：自动剔除“系列”、“合集”、“剧场版”、“第X季”、“Season”等干扰词后再进行主名收敛。
  - **孤岛保护**：同系列至少拥有指定部数（默认 $\ge 2$）时才真正建集，避免孤立条目污染合集库。
- 🔄 **反向清理机制**：当媒体源文件被删除或移走后，自动将其移出合集；合集清空后自动清理。
- 🧩 **原生嵌入 UI**：在 Emby 控制台插件页面中提供简洁直观的配置表单，支持自由添加系列别名与映射规则。
- ⏰ **原生计划任务**：无须宿主机或 NAS 支持 Cron，直接利用 Emby 内置计划任务按设定的周期自动巡检。
- ☁️ **GitHub 自动化构建**：本地无需安装开发环境，推送代码或发布 Tag 时由 GitHub Actions 自动编译输出 `.dll`。

## 🚀 安装与使用

### 1. 下载插件
前往本项目仓库的 [Releases 页面](../../releases)，下载最新版的 `Emby.CrossLibraryCollections.dll`（或 zip 压缩包并解压）。

### 2. 放置插件文件
将 `Emby.CrossLibraryCollections.dll` 放置于 Emby 服务端的 `plugins` 文件夹下：
- **Windows**: `C:\Users\<用户名>\AppData\Roaming\Emby-Server\programdata\plugins`
- **Docker**: 容器挂载的 `/config/plugins` 目录
- **群晖 / QNAP / Linux**: `~/.config/emby-server/plugins` 或 `/var/lib/emby-server/plugins`

### 3. 重启 Emby
重启 Emby Server，进入 **控制台 -> 插件**，即可看到 **Cross-Library Collections**。

## ⚙️ 配置说明

在 Emby 控制台点击本插件进入设置页面：

1. **运行与防护设置**：
   - **启用智能自动聚类**：根据清洗后的标题公共前缀自动推导同系列（如《鬼灭之刃》剧集与《鬼灭之刃 无限列车篇》电影）。
   - **最小成集条目数**：默认设为 `2`，防止库内只有单部电影时盲目建集。
   - **启用反向清理**：媒体库变动时保持合集状态整洁。
2. **自定义系列映射**：
   - 针对译名完全不相关但属于同一宏大宇宙的作品（如《复仇者联盟》与《洛基》），可在下方点击 **+ 添加系列映射**：
     - **合集名称**：`漫威电影宇宙`
     - **匹配关键词**：`复仇者联盟,钢铁侠,美国队长,雷神,洛基,旺达幻视`
3. **TMDb API Key (可选)**：
   - 留空时插件完全使用纯本地离线计算；填入后可在本地无法判断时向 TMDb 请求辅助数据（内置请求频率限流，保护 Key 不被风控）。
